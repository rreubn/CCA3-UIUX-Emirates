# Emirates Website — Comparative UX Evaluation (CCA3)

## 1. Project Overview

This project evaluates the usability of the original Emirates airline booking website against our modified high-fidelity Figma prototype. The objective is to determine whether our redesign improves the user experience through qualitative think-aloud testing and quantitative survey analysis.

The evaluation focuses on flight search, navigation, information presentation, flight selection, and the overall booking experience.

## 2. Project Objectives

- Evaluate the usability of the original Emirates flight-booking website.
- Test the redesigned high-fidelity Figma prototype.
- Identify usability problems through think-aloud sessions.
- Compare both versions using an 18-parameter UX survey.
- Determine whether the redesign improves the user experience and identify areas requiring further improvement.

## 5. Evaluation Methodology

### Participant Recruitment

Five participants who were not members of our project group were selected to participate in the usability evaluation.

### Think-Aloud Testing

Each participant was asked to perform the same flight-booking task on both the original Emirates website and our modified Figma prototype.

Participants were encouraged to verbalize their thoughts, expectations, difficulties, and reactions while completing the task.

Audio recordings were collected with participant consent, and transcripts were prepared for qualitative analysis.

### Quantitative UX Survey

Following the think-aloud sessions, participants completed the prescribed Google Form to rate both versions across 18 UX parameters.

**Survey Link:** https://forms.gle/wRXTGs5DTg3Qc7qu8

### Data Analysis

The qualitative analysis identifies recurring usability issues and examines whether the redesign addresses them. The quantitative analysis compares the average ratings of the original website and the modified prototype across the 18 parameters.
